# DFA-and-NFA-Implementation
Simulate a Deterministic Finite Automaton(DFA) and Nondeterministic Finite Automaton (NFA)

## Input file:
Starts with the number of the problem, followed by the input values for the problem, then “end” to
indicate the input for this problem is finished and to move to the next problem.
## Output file:
Starts with the number of the problem, followed by the corresponding output values of the input for
the problem, then “x” to indicate the output for this problem is finished and to move to the next
problem.

### DFA
#### Simulate a Deterministic Finite Automaton:
• The DFA's states

• The alphabet

• The transition function

• The start state

• The set of accepting states

You must simulate a Deterministic Finite Automaton (DFA) by implementing the
following components and ensuring correct DFA behavior:

States: Define the set of states in the DFA.

Alphabet: Specify the input symbols the DFA recognizes

Transition Function: Map each state-symbol pair to a next state.

Start State: Identify the initial state of the DFA

Accepting States: Define the set of states that indicate acceptance.

For each problem, pass the DFA configuration (States, Alphabet, Transition,
Start State, Accepting States) to your simulation class(or function) and ensure it
correctly processes input strings.
